## Алгоритм Якоби (по методичке, раздел 2)

- Шаг: `A_{i+1} = Pᵀᵢ · Aᵢ · Pᵢ`, где `P` — поворот Гивенса; `A₀ = A`, `V₀ = I`.
- Выбор зануляемого недиагонального элемента `A_pq`.
- `C = (A_qq − A_pp) / (2·A_pq)`.
- Тангенс (меньший корень, `|φ| < π/4`):
  `tg φ = 1/(C + √(C²+1))` при `C > 0`, иначе `1/(C − √(C²+1))`.
- `cos φ = 1/√(1+tg²φ)`, `sin φ = tg φ · cos φ`.
- Обновление A (формулы 12–15):
  - `A_pp ← A_pp − A_pq·tg φ`
  - `A_qq ← A_qq + A_pq·tg φ`
  - `A_pq = A_qp = 0`
  - для `r ≠ p,q`: `A_rp = A_pr ← A_rp − sin φ·(A_rq + (sin φ/(1+cos φ))·A_rp)`
  - для `r ≠ p,q`: `A_rq = A_qr ← A_rq + sin φ·(A_rp − (sin φ/(1+cos φ))·A_rq)`
- Обновление V (формулы 17–18), для всех `r`:
  - `V_rp ← V_rp·cos φ − V_rq·sin φ`
  - `V_rq ← V_rp·sin φ + V_rq·cos φ`
- Сумма квадратов недиагональных элементов: `S₀ = Σ_{r≠q}(A_rq)²`,
  `S_{i+1} = S_i − (A_pq)²`. Условие остановки: `S_{i+1} < ε`.
- Стратегия выбора `A_pq`: при программной реализации эффективен фиксированный
  порядок обхода (искать максимум неэффективно); для распараллеливания удобен
  обход по побочным диагоналям.
- Выход: диагональ `A_i` — собственные числа, столбцы `V_i` — собственные
  векторы.

## Требования задания (обязательны)

- Корректно работать для любой действительной симметричной матрицы.
- Для корректных входных данных: либо вернуть результат, либо остановиться
  с ошибкой. Зацикливание недопустимо (обязательно `max_iterations`).
- Не возвращать ошибки, кроме предусмотренных в дизайне.
- Спроектировать публичный интерфейс; превратить программу в пакет (crate).

## Соглашения по коду

- Публичный API минимальный и явный.
- `Result<T, E>` вместо паник на невалидных входных данных.
- Никаких `unwrap()` / `expect()` в публичных функциях.
- Все циклы с гарантированной сходимостью.
- Проверять, что вход квадратный, симметричный (`A == Aᵀ`), элементы конечны
  (не NaN, не inf).

pub struct JacobiSolver {
    pub max_iterations: usize,
    pub tolerance: f32,
}

impl JacobiSolver {
    pub fn new() -> Self;
    pub fn with_tolerance(self, eps: f32) -> Self;
    pub fn with_max_iterations(self, n: usize) -> Self;
    pub fn solve(&self, a: &DMatrix<f32>)
        -> Result<(DVector<f32>, DMatrix<f32>), JacobiError>;
}

pub enum JacobiError {
    NotSquare,
    NotSymmetric,
    NonFiniteElements,
    DidNotConverge { iterations: usize, residual: f32 },
}
