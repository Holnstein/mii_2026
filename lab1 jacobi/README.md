# Лабораторная работа 1 — Метод Якоби (Rust)

Вычисление собственных чисел и собственных векторов действительной
симметричной матрицы методом Якоби (циклические повороты Гивенса).

Предмет: **Нейронные сети глубокого обучения**, РХТУ им. Д. И. Менделеева,
преподаватель: **Сукин И. А.**

## Запуск

### Готовый exe (если Rust не установлен)

Бери [`bin/jacobi.exe`](bin/jacobi.exe) — собранная программа, ничего
дополнительно ставить не нужно, просто запусти:

```bash
bin\jacobi.exe
```

### Из исходников

Требуется [Rust](https://rust-lang.org) (cargo). Приложение — консольное,
меню интерактивное:

```bash
cargo run --release
```

Шаги программы:

1. Источник матрицы: ручной ввод (строки через пробел), случайная
   симметричная `A + Aᵀ` или файл (`.csv` — разделитель `;`, `.txt` — пробел;
   дробная часть через `.` или `,`).
2. Размерность, допустимо задать точность `ε` и максимум итераций
   (при пустом вводе — значения по умолчанию).
3. Вывод: матрица, остаточная сумма `S₀`, собственные числа, собственные
   векторы и невязка `‖A·V − V·diag(λ)‖`.

Прочее:

```bash
cargo build          # сборка
cargo test           # тесты
cargo clippy         # линтер
cargo doc --no-deps  # генерация документации API
```

## Что реализовано по ТЗ

- Метод Якоби для любой действительной симметричной матрицы (формулы
  методички: выбор `c`, тангенс, обновление `A` и `V`, критерий `S < ε`).
- Гарантия остановки: ограничение `max_iterations` + критерий по точности,
  зацикливание невозможно.
- Проверка входа: квадратность, симметричность, конечность элементов —
  через `Result`, без паник (`unwrap` в публичном API отсутствует).
- Пакет (crate): библиотека с публичным API + бинарник (CLI).
- Публичный интерфейс: `JacobiSolver` (`with_tolerance`,
  `with_max_iterations`, `solve`) и `JacobiError`.

## Структура

| Файл | Назначение |
|------|-----------|
| `src/lib.rs` | корень пакета, публичные модули, юнит-тесты |
| `src/jacobi.rs` | формулы: поворот, обновление `A` и `V`, сумма `S` |
| `src/solver.rs` | солвер `JacobiSolver::solve`, итерационный цикл |
| `src/error.rs` | `JacobiError` |
| `src/console_io.rs` | ввод/вывод, меню, парсеры файлов |
| `src/matrix.rs` | генерация и печать симметричной матрицы |
| `src/main.rs` | точка входа CLI |
